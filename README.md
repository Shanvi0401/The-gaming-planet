# 🎮 The Gaming Planet

**Welcome to The Gaming Planet — your destination for fun, interactive, and brain-teasing games!**

The Gaming Planet is a browser-based gaming website that brings together a collection of mini-games in one place. From testing your general knowledge and mathematical skills to enjoying classic games like Tic Tac Toe and Rock Paper Scissors, the platform offers an entertaining experience for players.

## ✨ Features

- 🎯 **Multiple Games:** Explore a variety of fun and interactive mini-games.
- 🧠 **Brain Training:** Challenge your knowledge, vocabulary, logic, and mathematical abilities.
- 🎨 **Custom Styling:** Individual CSS files for styling different webpages and games.
- ⚡ **Interactive Gameplay:** JavaScript powers the game logic and user interactions.
- 🌐 **Browser-Based:** Play directly in a web browser without installing a separate application.
- 📱 **Web Interface:** Navigate between the homepage, information pages, and individual games.

## 📄 Webpages and Game Descriptions

### 1. 🏠 Home Page — `home.html`

The main landing page of The Gaming Planet. It serves as the starting point for visitors, introducing the gaming website and providing access to its different games and sections.

**Technologies:** HTML5, CSS3

### 2. ℹ️ About Us — `aboutUs.html`

Provides information about The Gaming Planet, its purpose, and the gaming experience it aims to offer. It helps visitors learn more about the website.

**Technologies:** HTML5, CSS3

### 3. 📩 Contact Us — `contactUs.html`

A dedicated page for visitors who want to get in touch with the website's creators or share questions and feedback.

**Technologies:** HTML5, CSS3

### 4. 🧠 General Knowledge Quiz — `generalKnowledge.html`

A quiz-style game designed to challenge players with general knowledge questions. It encourages learning while making the experience fun and engaging.

**Technologies:** HTML5, CSS3, JavaScript

### 5. 🔢 Guess the Number — `guessTheNumber.html`

An interactive number-guessing game in which players try to identify a hidden number using their guesses and the feedback provided by the game.

**Technologies:** HTML5, CSS3, JavaScript

### 6. ➗ Maths Game — `maths.html`

A mathematical challenge designed to help players practise their arithmetic skills through interactive calculations and problem-solving.

**Technologies:** HTML5, CSS3, JavaScript

### 7. ✊ Rock Paper Scissors — `rockPaperScissors.html`

A digital version of the classic Rock Paper Scissors game. Players choose rock, paper, or scissors and compete against the game's opponent according to the traditional rules.

**Technologies:** HTML5, CSS3, JavaScript

### 8. ❌ Tic Tac Toe — `ticTacToe.html`

A digital implementation of the classic Tic Tac Toe game, where players place X and O symbols on a grid and try to form a winning line.

**Technologies:** HTML5, CSS3, JavaScript

### 9. 🔤 Word Scramble — `wordScramble.html`

A word puzzle game that challenges players to rearrange scrambled letters and discover the correct word. It encourages vocabulary development and logical thinking.

**Technologies:** HTML5, CSS3, JavaScript
